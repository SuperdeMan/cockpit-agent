## 2. 证据范围

- 告警状态和共同处置作为一个不可拆片段；未知灯状态同时呈现两种条件，不推断用户是哪一种。
- 压力参数与冷态/热态标签说明保留各自来源，不把阈值当推荐值。
- 复位段只在本步问题明确询问复位/未更新等情形时呈现；完整保留前提、步骤和仍未熄灭时的处置。
- 同步提供原页卡片、来源和片段 ID；来源指纹或片段不匹配时不输出其内容。
- 这是一个已核验主题的窄补口，不宣称所有手册生成均已保真；新增主题需独立证据登记和反例。
