## 2. 本轮抓修（7 处，全部已合入）

1. **跨厂商备份档 `LLM_BACKUP`**（`911b7c4`，泓舟指定 deepseek-v4-flash）：MiniMax 抖动
   期整批探针死；厂商内 fast=primary 同名+备档 MiMo key 失效=单点。8 条对照测试。
2. **方向词目的地拦截**（trip，`4b975bd`）：「北方追春天」被臆断成目的地→垃圾池+
   阿拉伯语天气；前缀匹配拦下追问（第一轮全等被穿透——**planner 臆断的槽值形态比
   预想的更野**）。
3. **轨迹候选挑选**（navigation，`4b975bd`）：描述性历史指代 dest 从「暂时无法确定」
   升级为列最近去过候选（确定性消费 episodic，挑的人是用户）。
4. **范例占位符**（`4b975bd`）：navigation#32 slots 里的占位描述被 planner 逐字抄进槽
   ——「范例写错只是噪声」的活例，slots 改空即愈。
5. **复合取消句吞句**（engine，本批）：wait_slot 挂起中「算了X不要了，**先去做Y**」
   整句被吞；剥取消词后余量 ≥6 字=复合句，清挂起后按新请求继续。纯取消句行为
   逐字不变（对照测试）。
6. **家人位置陈述误路由 set_place**（范例）：「我女儿在X小学上学」被反问「想设置
   哪个常用地点」——教学链整链卡死；chitchat 范例 ×2（家人位置=记忆抽取输入）。
7. **「找杯咖啡」被派去下单**（范例）：luckin.order 的槽校验错误「数量需要是 1 到
   20 之间的整数」当话术回给用户；nearby 范例锁发现语义。

## 3. 遗留清单（按值排序，均未立卡，出现真实消费方/复现再晋级）

1. **个人地点（学校/公司/家人处）作途经点**：waypoint 解析只走 POI 搜索；
   「先送孩子去学校再去公司」需要画像/关系地点进 waypoint 解析链（改动面=navigation
   waypoint 解析 + 画像读取，独立小刀）。
2. **多城 trip 用户点名 POI 保入池**：池来源现有「{城}景点/美食」+主题检索两路，
   点名 POI（大秋裤→东方之门）应作第三路（G4 同款接地纪律）。
3. **raw 槽校验错误文案直出**（话术层）：桥/Agent 的参数校验信息应经诚实降级话术
   包装（「数量需要是 1 到 20 之间的整数」不该原样 TTS）。
4. **散句 relation 抽取稳定性**：「我老婆平时在X上班」自由陈述抽成 semantic 偏好而
   非 relation 地点；导航内教学流（追问→回答）是稳通道，散句是软通道。
5. **负偏好降权 live 闭环复验**：机制+单测在，端到端一次干净复验（范例落位后）。
6. **provider 方差面**（档案化，不加码）：组合句偶发口头确认不执行（R7b）、
   过度澄清（「附近的咖啡店」clarify）、slot 填整句（R8b）——同属 findings §23/§24
   输出通道方差族，处置遵循「范例/台账不 hint」。
