## 1. 条件指令的后件（CA2-10 ②）

### 1.1 重证与根因

QA 交接登记的是「修后云端 T2 查完条件不派后件，改规划知识需 A/B」。先补了三条模拟车旅程（写车道，P3 授权）在当前线上 `65ddeb85`
标定 ×3：

| 旅程 | 原话 | 期望 | 修前 |
|---|---|---|---|
| D01 | 如果深圳今天不下雪，就把空调打开 | 查天气后开空调 | **0 / 3**：只查了天气，答「今天不会下雪」，空调没开 |
| D02 | 如果深圳今天下雪，就把空调打开 | 不动作 | 3 / 3 |
| D03 | 车里温度低于20度的时候打开空调 | 当下不执行 | 0 / 3：落成 `scene.create`「温度低开空调」要确认保存（不动车） |

D01 的 trace（`884df274…`）说明**不是规划知识的问题**：首轮升成 T2、查了天气；再规划**正确地**派出了 `hvac.on`，随后被问句闸拦下——
日志「Question-shaped utterance replanned into side-effecting step(s) ['hvac.on']; dropping before dispatch」。
整句判提问时假设框架（`HYPOTHETICAL_FRAMES`：如果 / 要是…）一律算提问，于是条件指令在首轮、在 T2 都被当成提问。
首轮这样判是对的（条件还没查，后件不许执行）；T2 观察在手之后还这样判，就是把条件指令整句废掉。
导航后件（RS14）不受影响，是因为这道闸只拦端侧写与声明需确认的云侧步。

### 1.2 修法

- 新判据 `question_shape.is_conditional_directive`：完整的「如果 / 要是 … 就 / 则 / 的话 + 后件」，后件不是提问（复用 `is_non_directive_question`）。
  切后件的正则与端侧整句上云的完整条件句同一组框架词与连接词（`deferred_condition.CONDITION_CONSEQUENT_RE`）。
  后件是提问（「如果开空调的话会不会更费电」）、没有完整「如果…就」（「如果你能去旅行，你想去哪里」）、等将来的条件（「温度低于20度时…」）都不算。
- `_filter_safety_origin_side_effect_steps(..., after_observation=True)` 对条件指令不按提问拦。只有拿到观察的两处传它：
  T2 再规划；恢复挂起计划（条件指令的后件写步首轮一律被拦、进不了挂起，挂起里的只可能出自再规划；不放行的话「如果…就打开后备箱」确认之后会被再删一次）。
  Agent 改派保持严格。首轮的问句闸逐字不变；需确认的照旧走确认，端侧写照旧过 VAL。
- 改闸前先量：collector 历史里带条件词的原话（模糊检索命中 26 种）过一遍新判据，只认出 3 句真正的条件指令，
  所有提问（怎么调 / 是什么意思 / 能不能…）都没被误认。
- D03 是另一件事（等将来的条件被落成场景、丢了条件）：不动车，安全性质成立；该怎么答待产品裁决，旅程标 `known_red`。

### 1.3 验证

- 判据 17 条、闸门 7 条、T2 循环 2 条、恢复挂起 2 条；变异 4 条全被抓（T2 / 恢复挂起不传「已观察」、闸门不看「已观察」、判据恒真）。
- 真栈：发布后 D01–D03 ×3 复测（D01 应转绿、D02 必须保持 3 / 3）。

## 2. 混合句里的时钟问句（P06）

- 现象：「打开充电口，顺便告诉我今天几号」，MiniMax-M3 偶尔把「今天几号」落成 `info.weather`（答一段天气）。线上 `65ddeb85` 基线 ×10：9 / 10
  （唯一失败即落天气）；更早 `ff9bce82` 3 / 5、`5afd98fd` 4 / 5。工具一侧早已兜住空槽（`7035ef68`），剩下的是规划方差。
- 为什么不做确定性改写：内置时间工具不是 Agent、没有 manifest，路由提示用不上；`Step.origin_text` 记的是整句原话、不是分句，
  认不出派错的那一步是从哪个分句来的——只能补一步时间工具，结果是天气、日期一起报。不改 `datetime.parse` 的描述（会把「明天几号」引到只会答当下的工具）。
- 修法：范例（写错只是噪声）——`skills/exemplars/datetime.yaml` 三条「车控 + 顺便问时间 / 日期 / 星期」，刻意避开 P06 原句。
  离线门禁通过；范例门禁提示「今天几号」单问会检回新范例（域错配率 3.6%，上限 20%），单问时钟由闲聊或时间工具答都是墙钟直答。
- A/B：同一组旅程在 `65ddeb85`（前）与新发布（后）各跑——P06 ×10，P01 / P02 / R07 ×3（单问时钟、挂起中问天气），信息家族 F08 ×1（天气不被吸走）。
  基线已跑：P06 9 / 10；P01 / P02 / R07 各 3 / 3；F08 12 / 13（A1-5 一条）。后测不比前测差才保留范例，否则撤回。
