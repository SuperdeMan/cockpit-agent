## 0. 结论

评审冻结的 `42596fd3` 就是当前 `main`。六条缺陷（R4-01～R4-06）在函数层**逐条复现**（§1 是本地复算读数），R4-07 是验证项。
复算额外核出两处比评审写的更糟：

- **R4-01 的危险形态不在「没有挂起」那一支**：挂着「打开后备箱」时，用户插话听了个故事，助手最后问「还要听吗？」，
  用户答「好的」——`_resolve_spoken_confirm` 只数 wait_confirm 条数，唯一一条就是它 ⇒ **后备箱被打开**。
  普通应答没有「它在回答哪一句」的判据，它就被最早那个事务确认吃掉。
- **R4-04 在真栈上位置丢得更早**：端侧快路径执行「打开副驾车窗」时，动作 payload 只带 `command`（结构化命令里的
  `positions` 从没离开端侧），上云的执行账本只有名字；即使是云侧执行过的控制，下一轮的账本覆盖也会把焦点里的位置清空。
  位置在三处丢，评审看到的只是最后一处。

裁决与评审一致：保留 DAG / Skill / 能力白名单 / VAL / 确认 / 执行核验；不开新 Agent、不扩词表当主路线。每条先写复现原问题的失败测试，
判据只留一份；验收含「原正常对照 + 新反例 + 组合 / 故障路径」，变异各自判红。落点是评审 §7 的三个关系：

### 5.1 现状表（对 `0ac21055` 源码逐条读，2026-09-24）

普通主链的受话判定是 planner 的 `addressed`，只在**规划那一刻**消费（`engine._orchestrate`：`is_voice_input_source(input_source) and not plan.addressed`
⇒ 静默拒识；语音来源 = `voice_*` 与 `ptt`）。在它之前出口的确定性分支：

| 出口 | 会改会话状态吗 | 语音来源时有没有受话判定 |
|---|---|---|
| 挂起表读不到 + 事务词 / 寻址键 | 否（只答「暂时读不到」） | 无（不需要：零改动） |
| 寻址键对不上挂起（`pending_missing`） | 撤客户端确认条 | 按钮路径，不涉及语音 |
| 裸确认 / 点名确认命中挂起（`one`） | **执行挂起步**（确认） | **§5.2 起有**：语音来源先过受话判定，判非受话 ⇒ 拒识、挂起保留；全局确认条按钮不问 |
| 取消判定（`detect_cancel`） | **关掉挂起** | **无，刻意不接**（§5.4）——背景里一句「算了」会作废一条挂起（方向 fail-safe：不执行，只丢）；反过来误拒一句真「取消」会把危险操作的挂起留下来 |
| 澄清选择（序数 / label） | **关澄清 + 执行选项** | **§5.4 起有**（语音来源；点卡不问） |
| 补槽续接（`wait_slot`） | **拿这句当槽值执行** | **§5.4 起有**（语音来源；判非受话不算一次没接上的重问） |
| 候选 / 会话事实 / 约束召回 / 记忆读不到 | 否（只读回答） | 无（不需要） |
| 纯偏好陈述（`constraint_noted`） | 登记会话约束 | **有**（评审二轮 R3：语音来源先跑一次 planner 只取 `addressed`） |

| S2S 自答 | 回灌历史（非移交轮） | provider 自己判（不经 engine 终态；`detect_false_promise` 只观测不拦截） |

结论：会改状态的五条确定性出口（确认 / 取消 / 澄清选择 / 补槽 / 焦点省略）在语音来源下都不消费受话判定。它们都不是本轮新引入的，
也都没有真实音频复现（评审同样只做了路径检查）。修法要在「每轮一次准入三态（已接纳 / 非受话 / 未知），确定性出口消费同一份」与
「这些出口各自再跑一次 planner 取 `addressed`」之间取舍——后者是纯偏好陈述那条的做法，代价是每条确认 / 取消 / 补槽多一次 LLM 往返（时延）；

待用户裁决方向**；过渡期风险最高的是免唤醒下的「焦点省略开关」（执行车控）与「确认」（执行挂起步）两条。

- goal 里逐字出现的旧值换成用户的回答（循环的锚跟着用户走；没出现就不动）——goal 是模型写的，补槽答案是用户说的，**用户在追问里给出的值胜过模型写下的锚**；
- 这一次续接里，循环再规划出的、槽值仍含旧值的步确定性丢掉（连同依赖它们的下游），丢光就收场；`t2.superseded` span 记下来。与「被拒诉求不许换能力再试」同一种做法：提示只是弱约束。

同一条路上还有一个次要推手：`ReplanDecision.to_plan` 一律写 `complexity=adaptive`，挂起时这一批原样存下，续接后第一次再规划就带着「首轮自报 adaptive、判 done 要纠偏一次」——
