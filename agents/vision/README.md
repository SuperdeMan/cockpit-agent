# vision —— 看一看（M4 P4 视觉入口）

「那是什么」单帧图片问答。设计见
`docs/design/2026-07-25-m4-p4-voiceprint-vision-rfc.md` §5，契约登记 `docs/conventions.md` §9.12。

## 它做什么 / 不做什么

- 能力：`vision.describe`（端口 50077）。用户指着窗外或车内的东西问「那是什么/这是什么车」，
  它看摄像头当前画面并用一两句口语回答。
- **本 Agent 拿不到图**——它只拿到一个 `frame_id`（16 字节），转给 llm-gateway，
  由网关从内存帧库取图拼多模态请求。**图像永不进对话链**：进了对话链的东西会进日志、
  进采集、进记忆，而这三者的生命周期都远长于「问一句那是什么」。
- v1 只做单帧问答。**不做**视频流实时理解、连续帧、人脸/视觉身份判定（与「声纹不作鉴权因子」
  同源）、多轮视觉追问（需帧的会话级驻留，v2）。

## 两条诚实降级（铁律③在视觉上的推论）

1. **没帧就说没帧**——`frame_id` 缺失或已过期时，**根本不调模型**（不给编造留机会）。
   看图问答编出来的答案比查不到严重得多：用户没法判断真假。
2. **看图模型不可用就说不可用**——不静默回落到看不了图的聊天大脑。实测 `qwen3.7-max`
   对多模态 content 直接 400，而档位解析对不认识的模型是**静默回落 primary**，
   故视觉走独立 `qwen-vl` 档 + 请求级 pin，整条降级链都能看图。

网关侧还会把「帧过期」与「模型挂了」分成两种回复——前者用户再问一次就好，后者再问也没用。

## 权限与隐私

- `camera.frame`（用户显式问一句时的**单帧**）≠ `camera.read`（连续流，`conventions.md` §3
  维持 ❌ 禁）。沿 `location.read`/`location.precise` 的精度分级先例。
- `context_scopes: [vision]`——不声明就收不到 `frame_id`（编排层最小化下发）。
- PoC 没有车外摄像头，画面来自设备摄像头：`_prov.source=simulated_camera` + 卡片角标
  「模拟车外摄像头」+ 设置文案，**三重诚实标注**（同 MCP 演示商户惯例）。
