## 2. 最小改动

- 复用 `AgentResult.data` 的保留键通道，增加布尔 `_speech_verbatim`。生产者决定其答案需要原文呈现，
  聚合核心不写手册、车型、胎压或 Agent 名的路由分支。
- manual-rag 在统一 `_safety_data` 出口声明此标记，包括来源不足、数值弃权和生成失败的诚实说明。
- 多结果中存在非空且明确声明的受保护答案时，整轮确定性组合原结果；只清理 Markdown 和收束句读，
  不再把其它结果交模型重写，以免模型仍根据整句问题补出与受保护答案冲突的数值。
- 卡片选择、动作合并、拒绝 follow_up 优先级、失败口径与 Verifier 说明继续使用既有出口。
  标记没有执行权、不能改变确认、不能抹掉失败；空历史引用不触发保护，没有声明的请求保持原聚合路径。
