- 主动播报类别头的「为什么收到」入口未做：代码里没有对应功能，只画了图标与类别文案。
- 行车常驻层的状态行仍是「说「小舟小舟」」：画板写「…，或轻点光球」，属文案改动，按计划先过计划 §5。
- 天气焦点日（问「明天天气」）的指标块取焦点日的湿度与风，不放今天的实时 AQI：画板焦点态那三块是从常态复制的，
  照画会把今天的读数摆在明天的预报旁边。画板没有的「生活建议」行没加。
- 车控结果卡：
  - 气泡出错（请求失败 / 超时 / 断链）时判「未核实」，不判计划写的「没生效」：三条出错路径都保留已到的动作帧，
    动作帧到了说明车端执行过，说「没生效」是假话。回执的「执行失败」同理改成同一套状态词。
  - pending_edge 判「未核实」并用服务端原话（「该操作已交给车端，尚未核实执行结果。」），不判计划写的「执行中」：
    final 之后没有任何东西会再更新这张卡，「执行中」会永远停在那里。「执行中」只给还在流式的这一轮。
  - 已执行的证据行写「车辆已执行（本次未做状态核验）」：画板「这类指令不做状态核验」不准——同类指令走云端时有核验。
  - `satisfied` 但没归属（`verified=false`）判「未核实」：`verified` 由共享投影重算，客户端不另造中间态。
- 行车摘要：
  - 充电路线不出「开始导航」：全量卡没有这个动作，发什么句子没有定义（画板有）。
  - 行程写「第一站」不写「下一站」：系统不知道走到哪了。
  - 副行严格 ≤2 个字段（周边列表画板 3 个，取距离 + 评分；行程「D1 3 个点」并成一个字段）。
  - 扫码支付副行给到期时刻（「14:30 过期」），不做倒计时：摘要不逐秒重渲。
- 空态（§5 拍板「空态改写建议」）：提醒空态照做（「说「明天 8 点提醒我加油」就能加一条」）；周边空态只给一句「附近没找到 X。」，
  画板上的「扩大到 5 公里 / 换一批」两个 chip 没做——`nearby.search` 的 radius 槽 2026-08-14 已作为零消费死槽摘除，
  provider 的 `page` 也没有调用方，两个 chip 点了都只会原样再搜一遍。同理删掉了周边列表提示行里的「「换一批」看更多」。
  后端补上半径 / 翻页后再加，属数据侧缺口（计划 §7 D20 同类）。
- 设置：开关说明保留代码里准确的说法，不照画板「仅在对话页生效」——保持常亮是全局的。
- 车况：页脚不写更新时刻，只给来源；宽屏画板多出的三格指标没做——胎压、里程不在车态里，车内温度在车态里有（明细里的 cabin_temp），
  但指标格是固定的电量 / 续航 / 挡位三格，没为宽屏单独加一格。
- 引导页：权限行保留完整说明；token 输入框占位写「粘贴访问 token」，不写画板的「末四位」——输入框不做末四位掩码。
- 地图侧栏（宽屏）每行只给名字 + 地址：地图页拿到的点没有评分 / 菜单。
- 隐私栏：「结束本轮收音」常驻（麦关着也给，作为一键止损），「关闭免唤醒」「关闭看图问答」只在对应开关开着时出——沿用旧判据。
- P7 天气 AQI：档位从数值行挪到标签行（「27」+「空气优」，四字档位直接写「中度污染」）；画板是「27 优」+「空气质量」，
  窄舞台截断、「156 中度污染」在对话列里也放不下。
- P7 音色格：两字名三列、四字名在手机外屏两列（列数 = 量到的宽度 ÷ 最长名字所需宽度，最多三列）。
- P7 地图：深色主题用高德夜间底图（对上 M 组深色画板），关掉缩放键与比例尺（画板没有，且被信息条压住），保留罗盘。
- P7 主题图标：字形按 07 页几何（环外径 48dp、线宽 4dp、一笔弧线）。画板把整张 108dp 画布画在展示圆里，
  桌面真正露出来的是中间 72dp，所以桌面上环占可见区约 2/3，比画板上看着大。

## 7. 观察（未改）

- 浅色主题下天气指标块看不出块：浅色 `surface/high` 与卡片 `surface` 都是 `#FFFFFF`（Figma 浅色画板同样看不出），
  信息仍按三列读得清。要块感需要一个「卡内嵌块」token（深色取 surfaceHigh、浅色取 surfaceLow 一类），属设计系统改动，
  动 Figma 变量与 theme.ts 两处，未在 P4 内做。
- 车况明细的数值没有单位（车内温度 24、车速 0、音量 30）：单位应由车态声明源给，客户端不另立一张单位表，未改。
- 隐私栏的说明段在外屏上要滚动才能看全，截在按钮上方、没有渐隐提示。
- 服务端：英文问「what time is it now」回的是「这个时间我没能换算出来，换个说法再试一次。」（手动验发送链路时看到；后端行为，未查根因，不在本计划）。
- 旧字号表 `TYPE` 仍被 Focus Dock 与 S2S 同意浮层直接使用（同意浮层有一处 14sp，v3 字阶没有这一档）；`GLASS` 材质常量只剩 blur-spike 诊断页在用。
