## 1. 方向与范围

从已经可运行的座舱 PoC，增量演进为**面向座舱与车辆服务的可验证 Agent Runtime**：
能够说明用户提出了什么、计划承接了什么、实际发生了什么、还有什么在等待或无法确认。
保留云边协同、gRPC/Manifest/Registry、T0/T1/T2、VAL、Task Ledger、Outcome Verifier、Memory 与主动引擎。

主线按 `基线 → 语义/结果/能力契约 → 可信状态 → 持久执行与授权 → 车辆服务闭环 → 集成试点` 推进。
Jev 与端侧小模型作为可消融的增强支线；它们的收益不成立时，主线仍可继续。

本轮依据是 [Jev 接入研究](research/2026-09-25-cockpit-agent-jev-integration-plan.md) 与
[v2 升级研究](research/2026-09-26-cockpit-agent-v2-upgrade-rfc.md)。采纳其边界与分期，
不把研究中的字段、时延目标、外部厂商展示或论文成绩登记为本项目已实现能力。

### 1.1 当前能力与真正增量

| 已有基础 | 后续增量 | 当前不能声称 |
|---|---|---|
| Step、T1 DAG、T2、来源原话、效果/确认元数据 | 稳定 goal_id、步骤消费范围、ResultBundle、持久往返 | 多目标结果已能完整跨挂起/跨端恢复 |
| Task Ledger、重复步骤指纹、Verifier 三态 | 操作 UUID、持久准入、一次确认、恢复对账、因果证据 | exactly-once、断电后安全自动续跑 |
| NATS 车态广播与多个镜像 | 认证车辆身份、逐信号时效、epoch/seq、局部陈旧 | 多车隔离已完成、模拟 VAL 等于真实车辆 |
| llm-gateway Complete/CompleteStream/Embed | 独立 Decide、校准/弃权、影子隔离与受控重排 | Jev 已接入或比现有模型更准 |
| 规则快路径、端侧 NLU shadow | 可选 T1e、车型 Schema 与目标板实验 | 完整离线语音、端侧模型已可执行车控 |
| 真实手册、导航/充电、MCP 商户与双端 | 能源/健康完整旅程、OEM 适配、委托身份 | 量产账号、车辆故障已排除、手机直接拥有 VHAL 权限 |

### 1.2 本次合并研究时的裁决

1. **稳定身份先于模型覆盖判断**：CA2-03 原位扩展 Step/SessionState，保留 `PLANNER_GOALS=off`。
   现有模型 `goals/covers` 只有实验/诊断意义；未知覆盖显式 unknown，不能按模型自报生成写授权。
2. **先修结果契约**：手册回答首句优化只是既有缓解；CA2-04 承接挂确认时兄弟步骤答案/引用丢失。
   Jev 重排不解决传输或展示裁剪。
3. **Jev 对齐 09-26 新检索链**：JV05 必须包含目录路由、仪表灯复合问句承接、词法首页保留和最终图片预算，
   不直接照 09-25 的纯词法接点开发。两层改动各自证明 off 等价。
4. **状态迁移是全链变更**：不能只给 Cloud 镜像加 vehicle_id；edge、网关、scene、collector 与验证方一起迁移。
5. **主动采用有条件**：先 JV00–JV03，首条在线候选为 JV04；JV05 单独实验/发布。
   capability/context、critic、记忆写相关治理不进入首批在线行为。
6. **历史问题继续有主表**：Android、会话评审、QA 的旧台账保持自己的编号和证据，本页只作映射。

## 2. 主线里程碑

周数从实际启动周计算。下表沿研究的 **3–5 名稳定投入人员**假设，角色覆盖后端/端侧、算法、客户端和 QA；
不代表已有这些人员，也不包含 OEM、采购、账号、数据审批和认证等待。具体人选与设备供给在 R0 登记。

| 阶段 | 参考窗口 | 交付 / 任务编号 | 退出条件 | 当前状态 |
|---|---|---|---|---|
| R0 基线与问题重证 | W1–W2 | CA2-01、CA2-21 起步；JV00 共用基线；现有关键残余复现与定界 | 可重跑的版本/数据/失败分类；代码、部署、APK 身份分开；延迟预算冻结 | 进行中：[首批实施记录](design/2026-09-26-v2-runtime-r0-r1-execution.md)，量尺已落地，先修 V207 |
| R1 契约与可信上下文 | W3–W6 | CA2-02–07、CA2-12 首版；步骤范围、稳定目标、结果集合、能力与车态信封 | 双端结果一致；两车/逐信号用例通过；旧读者兼容；无新增误执行 | 待 R0 |
| R2 可验证持久运行时 | W7–W10 | CA2-08–11、15；操作账本、确认绑定、执行点复核、对账/恢复 | 重放、ACK 丢失、断电、改参、撤销与换车有明确结果；账本不可用不放行新副作用档 | 待 R1 |
| R3 可选端侧有界规划 | W11–W14 | CA2-13–14；规则/固定能力表示/Schema/云对照；目标板预算 | 风险—覆盖—资源证据过线；离线能力逐项标明；无收益保持 shadow | 实验待条件 |
| R4 车辆服务与生态 | W15–W18 | CA2-17–19；一种真实/OEM 沙箱驱动，能源与健康两个旅程 | 请求→授权→接口→回执/状态→呈现闭环；来源可追溯；MCP 委托隔离 | 待接口及 R2 |
| R5 集成试点 | W19–W24 | CA2-16、22 收口，21 持续；多端/多人、休眠恢复、压力与回退 | 试点 DoD 与已知边界签收，回滚实演；量产另立范围与证据 | 待主线 |

关键依赖：`R0 → R1 → R2 → R4 → R5`。R3 在 R1 后可以准备模型实验；
写能力放量依赖 R2，R4 不等待 R3 成功。车辆接口资料、状态语义和硬件借测在 R0 就开始准备，不能等到 W15 才找。
CA2-12 仿真、CA2-16 交互与 CA2-21 评测是贯穿任务，表中阶段是首版或集中签收点。

### 2.1 个人或 1–2 人维护时

首个 8–12 周只安排 R0、R1 和 R2 核心子集：先混合诉求/挂起结果，再状态可信与操作身份；
Jev 先完成离线/契约和小规模校准准备。不要同时承诺全部模型、OEM、A2A 与 App 生产化。
每轮最多一个核心状态变更主题；有独立测试/模型人员时才并行相应工作，不能让多人同时改确认与持久化键集。

## 3. Jev 支线及主线依赖

| 工作包 | 本项目接续策略 | 进入下一档的证据 |
|---|---|---|

| JV05 | CA2-01 与 JV02 后可独立开发；先 RAG off 纯重构，再同池重排 | 09-26 检索链等价、图文一致、车型/hash/数值闸不退化；与 JV04 错峰启用 |
| JV06 | JV04 过线后再做 capability/context 建议；主线接口已变时复用 CA2-03/07 | 完整能力召回不降；只改变可选投影，不改变确定性事实与授权目录 |
| JV07 | JV03/06 后先 critic shadow；主动 critic 另过调度覆盖与共享重试门 | 不靠 goals/covers；任一适用步骤首次副作用前完成；每请求最多一次语义重规划 |
| JV08 | JV02 后离线 memory review；与 CA2-15 共用 owner/forget 语义 | 不自动合并/删除/写记忆，删除/撤权后在途结果失效 |
| JV09 | 每项自己的发布门，逐会话固定桶；不是最后一项统一开全量 | 故障演练与一键 off；账单、应用比例与用户时延可核对 |

没有 Jev 密钥仍可推进 JV00–02 的本地契约与 JV03 评测工具；真实分数/中文收益标未测。
研究建议的最多两次在线调用、总新增阻塞 500 ms 是实验上限，**不是现有配置或实测指标**。
原目录路由、聊天、TTS 和 Decide 消耗共同纳入端到端预算，不能各自宣布“只增加一点”。

## 5. 发布与验收规则

- 现有四道 blocking 门禁继续有效；新增目标指标先在 R0 冻结，再逐包转成可运行判据。
- 建议冻结 200 条核心旅程、每条独立 5 次，至少 95% 的旅程五次全达标；挑战集、拒绝过多、
  样本家族/相关性、置信区间另报。它是项目目标，当前没有完成这项测量。
- 安全必过集不允许新增误执行、越权、串车、确认重放或重复副作用；零观测失败只说明该测试集。
- 每包提交对应代码 SHA、模型/提示词/目录/策略/知识 hash、测试数据 split、设备与 artifact。
  状态为“实现完成 / 离线通过 / 真栈通过 / 已部署 / 已签收”中的哪一项必须写清。
- 数据迁移采用先加兼容读、再受控写、再切换消费的阶段，数据库与运行配置变更单独授权。
  回滚先停新写和新模型消费，再对账在途操作；不能只退代码就宣称回滚完成。
- 本轮授权覆盖文档提交与推送；不据此配置密钥、付费调用、修改 CI/CD、迁移数据库或部署。

## 6. 首轮可直接领取的工作

按实施方案的 PR-A→PR-D 顺序：CA2-01/JV00 共用冻结包 → CA2-02 步骤范围 →
CA2-03 稳定身份 → CA2-04 结果集合。JV01–02 可在边界冻结后独立做，不修改确认或执行分支。
外部输入缺失只阻塞对应实验：无目标板保留仿真，无 Jev 凭证保留契约，无 OEM 资料不宣称真实驱动。

可选 A2A（CA2-20）仅在真实合作需求和协议版本明确后立项；GUI Agent、自动驾驶世界模型、
端侧自由循环和全量 Kubernetes 迁移均不在本轮关键路径。
